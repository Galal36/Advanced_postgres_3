# AdvancedPostgres_3 Commands on School database

1. Create a multiply function that accepts two numbers and returns their
product.
2. Create a hello_world function that takes a name as input and returns a
personalized welcome message for that name.
3. Create a function that accepts a number and determines whether it is
odd or even.
4. Create a function that takes a Student ID as input and retrieves all
information related to that student.
5. Implement a function that takes the name of a subject and calculates
the average grades for that subject.
6. Create a trigger to automatically save deleted student records from the
Student table to the Deleted_Students table.
7. Create a trigger to monitor changes made to the student table,
including additions, updates, and deletions. This trigger will record
the time of each action and provide a description of the action in
another table
